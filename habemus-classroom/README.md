# Habemus Classroom · Frontend (React + Vite)

Las instrucciones completas para ejecutar el proyecto están en el
`README.md` de la carpeta principal.

Comandos de esta carpeta:

```bash
npm install     # instala las dependencias
npm run dev     # servidor de desarrollo en http://localhost:5173
npm run build   # versión de producción
npm run lint    # revisión con oxlint
```

La dirección de la API de Django se puede cambiar con un archivo `.env`:

```
VITE_API_URL=http://127.0.0.1:8000/api
```
